## 2. Install or request access

Open the app's **Installation** page before downloading. It explains supported operating systems, distribution channel, permissions, and first-run steps.

- Public downloads: follow the App Store or GitHub Releases link on the app overview.
- TestFlight and private-beta apps: use [Support and Feedback](/support/support-and-feedback) and include the app name and platform.
- Internal tools: request access through support before attempting installation.

## 3. Read the right guide

Each app follows the same map:

1. **Overview** explains the product, status, and supported platforms.
2. **Installation** covers access, requirements, permissions, and setup.
3. **Features** explains the main workflows and expected behavior.
4. **Gallery** shows the current interface and supported surfaces.
5. **Known Issues** lists limitations and workarounds.
6. **FAQ** answers common setup and usage questions.
7. **Changelog** records version-specific changes.

## 4. Before reporting a problem

Check the app's [Known Issues](/apps/index), [FAQ](/apps/index), and latest [Changelog](/changelog) first. Note the app version, build, device, operating-system version, and distribution channel. These details usually distinguish an installation problem from a platform limitation or app defect.
