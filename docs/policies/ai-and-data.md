# AI and data

This page explains the boundaries for AI-assisted features referenced by h3p apps and documentation.

## Source and consent

- The documentation helper is source-limited to published pages on apps-h3p.com. It does not access private repositories, local files, or credentials.
- AI features in an app are optional product features. The app should identify when a request leaves the device and give the user a meaningful choice before sending content.
- Do not paste secrets, API keys, personal data, or confidential source into an AI prompt unless the app’s current privacy documentation explicitly covers that flow.

## Data handling

The site does not use the documentation helper to make background network requests. Product-specific behavior is documented on each app’s privacy page. When no dedicated policy exists, the [website Privacy Policy](/policies/privacy-policy) is the governing reference.

## Better answers and source fidelity

AI output is a draft, not an authority. Verify code against the language’s compiler, formatter, or linter and verify factual claims against the linked source. Support requests should include the page URL and a minimal reproduction rather than private project content.

See the [docs assistant](/support/docs-assistant), [Security and Trust](/policies/security-and-trust), and [All Apps](/apps/index).
