# Lingua Latina Changelog

## 1.6.1 (App Store, October 2026)

- Improved Latin morphology, including perfect-tense verbs and regular first-declension nouns, and made offline dictionary results more reliable.
- Strengthened translation checks for omitted sentences, questions, and negation; marked AI translations and tentative matches clearly.
- Fixed question routing, stale answers after changing language or answer mode, and incomplete responses; improved English/German consistency.

## October project release train: 1.7–1.8.2 (through build 325)

These are prepared project builds, not the current App Store version. Apple's listing showed 1.6.1 when checked October 27, 2026.

- **1.7 (build 314):** clearer Ask results, spaced-review sessions, curated vocabulary, study-data backup/import, provider controls, and additional morphology corrections.
- **1.8 (build 315):** restored the title and direct-question home cards, improved headings, and adapted layouts for iPhone Duo.
- **1.8.1 (build 316):** prepared full-screen iPhone Duo support using the iOS 27.1 SDK.
- **1.8.2 (build 325):** fixed stale question text sent by Answer and tightened grammar-topic matching.

## 1.6 (App Store, September 12, 2026)

- Added a History Vision-inspired background, theme-aware dictionary details, and light/dark previews.
- Adopted Apple Foundation Models APIs for the iOS 27, macOS 27, and visionOS 27 SDKs and improved translation, sentence analysis, and grammar guidance.

## 1.1.0 (published August 8, 2026)

- App Store release metadata synced to the public app documentation.

- App Store listing verified as Lingua Latina by Hilthart Pedersen.
