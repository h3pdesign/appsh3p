# Privacy Policy for Lingua Latina

_Last updated: April 30, 2026_

Lingua Latina is a Latin learning app. The app does not require an account and does not include ads, tracking, or developer telemetry. The developer does not collect data from this app.

## Data Stored Locally

The app stores settings, favorites, study progress, recently used content, and optionally saved study cards locally on the device. This data is used only for app functionality and is not automatically transmitted to developer-controlled servers.

## Apple Intelligence

When Apple Intelligence is available, the app can use the system model for open questions, sentence analysis, and translations. Processing is handled through Apple's system functionality. The developer does not operate a server for this path and does not collect these requests.

## Optional AI Providers

OpenAI is optional. The app uses OpenAI only if users select OpenAI in Settings and store an API key. The API key is stored in the system Keychain.

Local models, for example through LM Studio, are optional. The app sends requests only to the OpenAI-compatible URL configured by users.

If an external or local provider is explicitly enabled, the app sends only the text context needed for the specific request, such as the entered question, selected sentence, or active word form. The app does not automatically transmit full databases, study progress, device contacts, location data, unrelated files, or device identifiers.

## Offline Database

Some builds may include a local Latin dictionary database. This database is read-only inside the app bundle and does not contain user data.

## No Ads or Tracking

The app does not use tracking technologies and does not share data with third parties for advertising or tracking. There is no developer analytics and no background behavioral measurement.
