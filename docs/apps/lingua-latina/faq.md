# Lingua Latina FAQ

## Does Lingua Latina require an account?

No. The app does not require an account.

## Does the app work offline?

Core local workflows are designed to be offline-first when a bundled database is included in the build. Some free-form AI questions require Apple Intelligence or a user-configured provider.

## Which languages are supported?

The app supports German and English output modes.

## Are API keys stored securely?

Yes. Optional external provider keys are stored in Keychain.

## Is the repository public?

No. The repository is not publicly listed yet.
