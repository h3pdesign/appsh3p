## Application Purpose

Lingua Latina is a native Apple-platform app for Latin language learning, dictionary lookup, morphology analysis, grammar reference, and vocabulary study.

Primary user outcomes:

- look up Latin lemmas and inflected forms quickly
- review morphology parses for ambiguous word forms
- read grammar explanations in German or English
- save words, build decks, and review vocabulary
- ask optional AI-assisted questions without changing the local-first core workflow

## Product Focus

Lingua Latina prioritizes speed, clarity, offline capability, native Apple UX, and optional AI assistance.

The app uses a single active language mode:

- German UI produces German dictionary, grammar, and quiz output.
- English UI produces English dictionary, grammar, and quiz output.

## Data Sources

The app can use a bundled read-only Latin database when included in the build. If the database is absent, the app still starts and can use Apple Intelligence for supported free-form sentence questions.

Optional external AI providers are user-selected in Settings. API keys are stored in Keychain.
