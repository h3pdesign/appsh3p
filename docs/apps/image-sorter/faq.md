# Image Sorter FAQ

## Is Image Sorter AI available?

Yes. Version 1.0 is available for Mac on the [App Store](https://apps.apple.com/us/app/image-sorter-ai/id6832581913).

## Is Image Sorter available on iOS or iPadOS?

No. Current documented target is macOS.

## Do I need the companion server?

No. Local processing works without server integration.
