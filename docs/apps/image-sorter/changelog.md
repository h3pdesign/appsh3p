# Image Sorter Changelog

## 1.0 App Store release (November 20, 2026)

- Initial Mac App Store release of Image Sorter AI.
- Includes the safer image recognition and file-operation checks, faster review queue, and output-numbering controls documented below.

## Development updates (October 12–26, 2026)

- Hardened image recognition, file-safety checks, and the review workflow; added regression coverage.
- Improved review-queue performance and usability, including clearer numbering-width controls.
- Added StoreKit purchase infrastructure and an About/settings page, plus debug screenshot launch options and refreshed app icon artwork.

## 0.1 (published April 30, 2026)

- Synced documentation metadata with the local Image Sorter project version and build number.
- Initial documentation set added to h3p apps.
- Overview, install, features, and support pages published.
