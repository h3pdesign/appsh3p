# History Vision Installation

## Requirements

- iPhone or iPad running iOS/iPadOS 17 or later.
- Mac running macOS 14 or later.
- Apple Watch running watchOS 10 or later for the companion app.
- A current Xcode installation for source builds.

## Local Setup

1. Open `History Vision.xcodeproj`.
2. Select `HistoryVision-iOS`, `HistoryVision-macOS`, or `HistoryVision-watchOS`.
3. Choose a compatible device or simulator and build the selected scheme.
4. For Watch testing, build the iOS app so the embedded companion is installed with it.
