# Liquid Record FAQ

## Is Liquid Record public?

No. It is currently documented as a private alpha app.

## Does it require an account?

No. The current requirements specify offline operation with no account or network requirement.

## What audio format does it record?

The default target is uncompressed PCM WAV, using 48 kHz and 24-bit where supported. The app must display the actual negotiated hardware format.

## Where are recordings stored?

User-created recordings are stored in `Documents/Liquid Record/Recordings/`. Metadata and regenerated waveform artifacts are stored in Application Support.

## Does the app claim hardware gain control?

No. The gain control must show when hardware gain is not controllable and must not pretend to change iPhone microphone gain when iOS does not allow it.
