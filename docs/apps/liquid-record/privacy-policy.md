# Liquid Record Privacy Policy

Liquid Record is designed as an offline-first local audio recorder.

## Microphone Access

Microphone permission is requested only from the first record action. If permission is denied, the console remains accessible and should provide a path to Settings.

## Local Data

- Recordings are saved locally as user-created audio files.
- Recording metadata, markers, notes, waveform cache data, and app settings remain local to the device.
- Export uses temporary staging before handing the file to the system share flow.

## Network and Accounts

The v1 scope does not require an account or network access. Cloud sync, transcription, and account-backed workflows are out of scope.
