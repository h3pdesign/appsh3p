## Application Purpose

Liquid Record is designed for local, offline-first WAV capture on iPhone and iPad. The app keeps recording, pause, stop, monitoring, playback, scrubbing, markers, notes, rename, export, and library management available without moving users into a separate recorder tab.

Primary user outcomes:

- record, pause, resume, finalize, and play WAV files from the main console
- monitor L/R levels, waveform progress, input route, and elapsed time
- add markers and time-coded notes while recording or reviewing
- rename, duplicate, delete, and export recordings from the library flow
- import and export audio through Apple Files
- transcribe recordings on device and create optional on-device summaries on supported devices
- organize podcast projects and link a public podcast RSS feed without sharing Spotify credentials

## Current Scope

The current release targets iPhone and iPad with local files, SwiftData metadata, AVAudioEngine recording, selectable compatible audio inputs, Apple Files import and export, and an offline-first workflow. One recording with playback is available at no cost. A one-time Full Access purchase unlocks unlimited recordings and the complete production toolset; there is no subscription.
