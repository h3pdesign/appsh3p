# Liquid Record Installation

## Status

Liquid Record 1.0.4 is available from the [App Store](https://apps.apple.com/us/app/liquid-record-audio-recorder/id6812232944). The listing was checked on October 27, 2026.

## Requirements

- iPhone.
- iOS 17 or later.
- Microphone permission.
- Local storage for WAV recordings and waveform metadata.

## Install

1. Open [Liquid Record: Audio Recorder](https://apps.apple.com/us/app/liquid-record-audio-recorder/id6812232944) on the App Store.
2. Install the app on a supported Apple device.
3. Allow microphone access when you choose to record, and Speech Recognition access only if you choose to transcribe.

## Source Build Notes

The current public App Store version is **1.0.4**. The project release log records 1.1.1 build 73 as submitted October 26; it is not listed publicly yet. The Xcode project bundle identifier is `com.h3p.LiquidRecord`.
