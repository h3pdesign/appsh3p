# Changelog

This is the combined release history for the H3P apps documentation site. It includes published app changes wherever an app changelog is available. Open the linked app changelog for complete notes, screenshots, requirements, and access information.

## September 2026

### History Vision 1.0 beta - September 12

- Expanded the searchable library to 295 bundled articles with source-backed reading, inline references, related people and inventions, private notes, and review state.
- Added Discover recommendations, Continue Reading, period and region browsing, optional daily features, and clearly labelled optional Apple Foundation Models assistance.
- Reworked chronology around 13,387 dated records with comparison, filtering, uncertainty semantics, and an archived-reference layer.
- Added an offline Apple Watch companion for briefs, chronology, sources, and reading-list handoff.

[Read the History Vision changelog](/apps/history-vision/changelog)

### Neon Vision Editor 1.7.6 - September 12

- Keeps long and wrapped macOS documents intact while scrolling and repaints only the visible Core Text canvas region.
- Prevents stale AppKit backing pixels from covering or clipping editor lines.
- Keeps the bounded virtual-editor layout and redraw behavior intact; no breaking changes or migration steps are required.

[Read the Neon Vision Editor changelog](/apps/neon-vision-editor/changelog)

### Neon Vision Editor 1.6.4–1.6.0 - September 3–8

- Added native macOS window dragging, first-frame tab switching, bounded large-file rendering, HEX color swatches, Emmet and mobile editor improvements, and generation-safe viewport performance work.
- Improved Markdown PDF export, Find in Files exclusions, external-file recovery, UTF-16 editing boundaries, syntax tokenization, and editor persistence across platform surfaces.

[Read the detailed Neon release history](/apps/neon-vision-editor/changelog)

### GitBird 2.1.4 - August 5

- Moved provider tokens to macOS Keychain and restricted provider requests to approved HTTPS hosts.

- Prevented stale refresh and bulk-action results from replacing newer account state.
